# Social Census

Independent analytics project split from Loomic.

- Run locally: `npm install` then `npm run dev` (port 3002)
- Copy the existing Loomic `.env` values into this project to reuse the same database, Meta/provider credentials, accounts, clients, team and workspace data.
- Includes Dashboard, Analytics, Accounts, Team and Settings. Composer, Calendar, Queue and publishing worker UI are intentionally excluded.
- The analytics sync endpoint and account/provider connection routes remain available.
- The original Loomic project is not modified.
